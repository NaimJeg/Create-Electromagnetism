# electromagnetism：设备模型与电磁扩展设计

修订日期：2026-11-03。本文是重构设计基线，未实现的接口、诊断和性能目标均为待验证方案。

## 重构前提

CEE 已具备实验性交流玩法，包括微步进、三相发电、频率表、同步表和三相变压器连接。实验性不等于没有 AC；本项目优先复用其电网拓扑、求解过程和既有交流元件。[上游交流说明](https://github.com/george8188625/Create-Electro-Energetics/wiki/Alternating-Current)

重构重点是设备模型与世界对象的边界、物理时间步与非线性迭代的关系、扩展域与电网之间的功率耦合，以及验证和故障诊断。只有可复现的能力缺口或性能基准证明必要时，才改动求解内核。

保留现有灯具、加热、励磁、半导体等内容，继续探索无线电和仪器。允许重构底层不代表必须移除 CEE；本路线不以重新实现交流为目标。

## 架构约束

- 同一片相连的电气网络只有一个最终决定节点电压、电流的求解权威：当前为 CEE。
- 本项目拆出可脱离游戏测试的设备数学模型与状态，经集中适配层接入 CEE。
- 优先使用已核实版本的设备生命周期、微步及事件接口；接口不足时记录缺口，评估局部扩展。
- 固定微步下先明确接受、失败、状态提交语义；自适应时间步和新分析后端不作为首期前提。
- 高频采用单独抽象，通过受功率约束的源／负载双向耦合；不覆盖 CEE 已求出的节点电压。
